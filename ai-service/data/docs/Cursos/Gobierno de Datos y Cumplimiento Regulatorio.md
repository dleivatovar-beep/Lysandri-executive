# Gobierno de Datos y Cumplimiento Regulatorio

## Estado del sílabo
BORRADOR PARA REVISIÓN. Este temario fue preparado durante el proyecto de mejora y no acredita que la empresa lo haya impartido o aprobado. Las condiciones no confirmadas no deben presentarse como definitivas.

## Objetivo propuesto
Proponer responsabilidades y controles para administrar datos corporativos de forma trazable.

## Organización propuesta
Se plantean cuatro módulos para distribuir las 6 horas registradas en el catálogo. La distribución y las actividades requieren revisión académica.

## Temario propuesto
El sílabo de Gobierno de Datos y Cumplimiento Regulatorio propone cuatro módulos:
1. Datos y responsabilidades: Activos de información, propietarios de datos y funciones de custodia.
2. Calidad y catálogo: Criterios de calidad, metadatos, linaje y descripción de un conjunto de datos.
3. Privacidad y uso: Finalidad del tratamiento, acceso y conservación. Revisión conceptual de GDPR; no sustituye asesoría legal aplicable al caso.
4. Propuesta de gobierno: Definición de controles, responsables y evidencias para un caso de gestión de información.
