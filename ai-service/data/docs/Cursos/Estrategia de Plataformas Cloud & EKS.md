# Estrategia de Plataformas Cloud & EKS

## Estado del sílabo
BORRADOR PARA REVISIÓN. Este temario fue preparado durante el proyecto de mejora y no acredita que la empresa lo haya impartido o aprobado. Las condiciones no confirmadas no deben presentarse como definitivas.

## Objetivo propuesto
Comparar alternativas de plataforma cloud y evaluar cuándo una solución basada en Kubernetes resulta adecuada.

## Organización propuesta
Se plantean cuatro módulos para distribuir las 10 horas registradas en el catálogo. La distribución y las actividades requieren revisión académica.

## Temario propuesto
El sílabo de Estrategia de Plataformas Cloud & EKS propone cuatro módulos:
1. Estrategia de plataforma: Necesidades del negocio, modernización y criterios para elegir servicios administrados.
2. Kubernetes y EKS: Contenedores, clústeres, cargas de trabajo y responsabilidades de operación.
3. Operación y riesgos: Acceso, observabilidad, continuidad y costos. Consideraciones de una estrategia multicloud.
4. Evaluación de una plataforma: Propuesta de arquitectura con supuestos, alternativas y criterios de adopción; no exige contratar servicios para revisar el caso.
